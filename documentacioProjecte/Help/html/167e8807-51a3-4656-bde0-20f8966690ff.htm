Benvingut a la documentació de l'API de SecureCore G7, una aplicació d'escriptori Windows Forms desenvolupada amb .NET Framework 4.7.2. L'aplicació gestiona l'autenticació d'usuaris amb hash PBKDF2, control d'accés per nivells i manteniment de dades mitjançant pantalles genèriques CRUD.

Arquitectura de l'aplicació

L'aplicació s'estructura en capes ben definides. El flux d'execució comença a Program.Main, que obre la pantalla de presentació (frmSplashScreen). Aquesta gestiona tot el cicle d'autenticació i navegació principal.

Copy
Program.Main()
  └─ frmSplashScreen          (presentació + àudio)
       └─ frmLogin             (autenticació PBKDF2)
            ├─ frmCambioPassword  (primer accés)
            └─ frmBenvinguda      (benvinguda + progrés)
                 └─ frmPrincipal  (menú principal per nivell d'accés)
Mòduls principals
Autenticació (Login)

frmLogin valida les credencials contra la base de dades. GestorPasswords s'encarrega de generar salts de 24 bytes, calcular hash PBKDF2 amb 10 101 iteracions i verificar paraules de pas. UsuariosBD proporciona l'accés parametritzat a SQL Server.

Pantalla principal (Principal)

frmPrincipal carrega les opcions de menú filtrades pel nivell d'accés de l'usuari autenticat (via PrincipalBD). Cada targeta del menú és un control SWLauchForm que obre el formulari corresponent per reflexió.

Formulari base CRUD (FormBase)

frmBase ofereix operacions CRUD genèriques sobre qualsevol taula de la base de dades. Les subclasses sobreescriuen ConfigurarDGV per personalitzar la graella. La capa de dades és AccesoDatos, que utilitza SqlDataAdapter i SqlCommandBuilder.

Controls personalitzats

SWTextBox estén TextBox amb validació de format (text lliure, número o codi SecureCore), metadades per a DataBinding i canvi de color en focus. TipoDato és l'enumeració que governa la validació.

Reflexió

CreadorFormularios.Crear instancia qualsevol formulari WinForms per reflexió a partir del seu nom complet, desacoblant el codi de navegació dels tipus concrets.

Seguretat de les paraules de pas

SecureCore G7 implementa emmagatzematge segur de paraules de pas seguint les millors pràctiques criptogràfiques:

  1. En el primer accés, la paraula de pas inicial (GestorPasswords.PasswordInicial) es substitueix per una de nova que compleixi els requisits mínims.

  2. Es genera un salt aleatori de 24 bytes amb RNGCryptoServiceProvider.

  3. Es calcula el hash PBKDF2 (SHA-1, 10 101 iteracions, 24 bytes de sortida) amb Rfc2898DeriveBytes.

  4. Salt i hash es desen en format hexadecimal a la taula d'usuaris de SQL Server.
