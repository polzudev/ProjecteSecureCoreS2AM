frmBase Class

Formulari base de manteniment genèric que gestiona les operacions CRUD sobre una taula de la base de dades. Hereta d'aquest formulari qualsevol pantalla de manteniment del projecte; la propietat Tabla n'indica la taula destí. Les subclasses poden sobreescriure ConfigurarDGV per personalitzar la graella.
